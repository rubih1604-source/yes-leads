גרסה 201
=========

כוללת את 200 (התראות נייד + תזכורות חזרה).
מה שחדש כאן: שמות קמפיין מחשבון מודעות שלא משויך.


התיקון האמיתי הוא בפייסבוק, לא בקוד
-------------------------------------

שמות הקמפיין, קבוצת המודעות והמודעה הם שדות של **חשבון
המודעות**, לא של העמוד. הטוקן שלנו הוא טוקן עמוד, ולכן
פייסבוק מחזירה אותם רק מחשבונות מודעות שמשויכים אליו.

המזהים חוזרים תמיד - ולכן בלידים החדשים נשמרו המזהים
אבל לא השמות.

כדי לתקן:
  business.facebook.com
  -> הגדרות עסק (Business Settings)
  -> משתמשים -> משתמשי מערכת
  -> המשתמש שהנפיק את הטוקן
  -> הוספת נכסים (Add Assets)
  -> חשבונות מודעות -> לסמן את חשבון המודעות החדש
  -> להפעיל לפחות "הצגת ביצועים" (ads_read)
  -> שמירה

מאותו רגע לידים חדשים יגיעו עם השמות.


מה לעשות, לפי הסדר
--------------------

1. להעלות את ה-ZIP לגיטהאב.

2. לחכות לדפלוי. יומן קליטה -> למטה "גרסה 201".

3. לשייך את חשבון המודעות במטא, לפי ההוראות למעלה.

4. תחזוקה -> "השלם שמות קמפיין ללידים שחסרים"
   -> קודם "הצג": רואים כמה לידים מחכים.
   -> אחר כך "הפעל": מושך את השמות גם ללידים שכבר נכנסו.

   אם התוצאה היא "אף שם לא הושלם" - סימן שהשיוך במטא
   עדיין לא נתפס. לחכות דקה ולנסות שוב.

5. לבדוק: למלא טופס מהקמפיין החדש. במייל צריכים להופיע
   קמפיין, קבוצת מודעות ומודעה בשמות.


מה השתנה בינתיים, עד שתשייך
-----------------------------

במקום שורות ריקות, המייל והכרטיס מציגים עכשיו את
המזהים ("קמפיין: מזהה 120212345678") ושורת הסבר למה
השמות חסרים. מזהה פחות נוח משם, אבל אפשר לחפש אותו
במנהל המודעות וזה מזהה את הקמפיין בוודאות.
