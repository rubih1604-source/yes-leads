גרסה 208
=========

כוללת את 207 ואת כל מה שלפניו.
החידוש: חשבון פייסבוק שני, בלי שום קשר לראשון.


מה היה חסר
------------
המערכת הכירה אפליקציית פייסבוק אחת: סוד אחד לאימות
החתימה וטוקן אחד לשליפת הליד.

כלומר הדרך היחידה לחבר פייסבוק נוסף הייתה להשתמש
באותה אפליקציה של החשבון הקודם - וזה בדיוק החוט המקשר
שלא רצית.


מה שאפשר עכשיו
----------------
חשבון פייסבוק חדש לגמרי, אפליקציה חדשה משלו, בלי אף
אדמין משותף ובלי תיק עסקי משותף - והלידים נכנסים לאותה
מערכת.

הגדרה: אותם שמות עם _2 בסוף.

  FB_APP_SECRET_2
  FB_PAGE_TOKEN_2
  FB_VERIFY_TOKEN_2

החתימה נבדקת מול כל הסודות, והליד נשלף עם כל טוקן עד
שאחד מצליח. לכן **אין צורך לרשום איזה עמוד שייך לאיזו
אפליקציה** - זו עוד הגדרה שאפשר לטעות בה, וטעות בה
פירושה לידים שנופלים.

גם ההשוואה מול פייסבוק ("מי קיים שם ולא אצלנו") מכסה
את שני החשבונות. בלי זה רשת הביטחון פשוט לא הייתה
מכסה את החדש.


מה לעשות בפייסבוק
-------------------
1. לפתוח את החשבון החדש ואת העמוד החדש.

2. developers.facebook.com -> Create App -> Business.
   זו אפליקציה **חדשה** של החשבון החדש. לא לגעת
   בקיימת.

3. באפליקציה: Add Product -> Webhooks -> Page
   Callback URL:
     https://yes-leads.onrender.com/api/webhooks/facebook
   Verify Token: מחרוזת שתמציא (למשל fbverify2026b)
   Subscribe to: leadgen

4. Add Product -> Facebook Login for Business, ולהפיק
   טוקן עמוד ארוך-טווח לעמוד החדש עם ההרשאות:
     pages_show_list
     pages_read_engagement
     leads_retrieval
     pages_manage_metadata

5. App Settings -> Basic -> להעתיק את App Secret.


מה לעשות ברנדר
----------------
Environment -> להוסיף שלושה משתנים:

  FB_APP_SECRET_2    = ה-App Secret של האפליקציה החדשה
  FB_PAGE_TOKEN_2    = טוקן העמוד החדש
  FB_VERIFY_TOKEN_2  = אותה מחרוזת מסעיף 3

לשמור. רנדר יעשה דפלוי לבד.


בדיקה
------
1. יומן קליטה -> "גרסה 208".
2. למלא את הטופס החדש בפייסבוק.
3. הליד צריך להיכנס, ולהגיע עליו התראה בנייד.
4. אם לא - יומן קליטה יראה בדיוק מה חסר:
   "החתימה לא תאמה לאף אחד מהסודות" -> FB_APP_SECRET_2
   "אף אחד מהטוקנים לא הצליח"       -> FB_PAGE_TOKEN_2


הערה אחת
----------
המערכת לא תדע להבדיל בין לידים של שני החשבונות אלא לפי
שם הקמפיין והטופס. אם תרצה הפרדה מלאה - ערוץ נפרד,
דוחות נפרדים - תגיד ונוסיף.
