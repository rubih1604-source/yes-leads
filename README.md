# שלב 1 — הבסיס

## מה יש כאן

מערכת שקולטת לידים מליד מנגר, שומרת אותם אצלך, ומאפשרת לך לשנות סטטוס מהנייד.

**ארבעה מסכים:**

| מסך | כתובת | מה הוא עושה |
|---|---|---|
| רשימת לידים | `/` | חיפוש, סינון לפי סטטוס, שינוי סטטוס בנגיעה |
| כרטיס ליד | `/leads/...` | פרטים, כפתור חיוג, ויומן של כל מה שקרה לו |
| יומן קליטה | `/incoming` | מה בדיוק הגיע מליד מנגר — לזה נשתמש כדי למפות שדות |
| כניסה | `/login` | סיסמה אחת, שלך |

---

## ההתקנה — 6 צעדים

### 1. פתח חשבון ב-Render

היכנס ל‑render.com והירשם.

### 2. צור בסיס נתונים

`New` ← `Postgres` ← בחר את המסלול הזול בתשלום ← `Create`.
העתק את ה‑**Internal Database URL** שהוא נותן לך.

### 3. העלה את הקוד ל-GitHub

צור מאגר חדש והעלה אליו את התיקייה הזו.

### 4. צור את השירות

`New` ← `Web Service` ← בחר את המאגר.

- **Build Command:** `npm install && npx prisma db push && npm run build`
- **Start Command:** `npm start`
- **מסלול:** בתשלום. **לא free** — שירות חינמי נרדם, ו־webhook שמגיע לשירות ישן = ליד שנעלם.

### 5. הגדר את המשתנים

בלשונית `Environment` הוסף:

| שם | ערך |
|---|---|
| `DATABASE_URL` | מה שהעתקת בשלב 2 |
| `APP_PASSWORD` | סיסמה שאתה בוחר, לכניסה למערכת |
| `SESSION_SECRET` | מחרוזת אקראית ארוכה, לא משנה מה |
| `LEADMANAGER_WEBHOOK_TOKEN` | טוקן סודי שאתה ממציא |

### 6. חבר את ליד מנגר

הכתובת שתיתן לו:

```
https://<הכתובת-שלך>.onrender.com/api/webhooks/leadmanager?token=<הטוקן-מהשלב-הקודם>
```

---

## איך יודעים שזה עובד

1. היכנס לכתובת שלך → אמור לבקש סיסמה
2. שנה סטטוס לליד אמיתי בליד מנגר
3. פתח `/incoming` → אמורה להופיע שם השורה שהגיעה
4. פתח את הרשימה → הליד אמור להיות שם
5. שנה לו סטטוס מהנייד → אמור להשתנות מיד
6. פתח את הכרטיס שלו → השינוי אמור להופיע ביומן

**אם שלב 3 עובד אבל שלב 4 לא** — הגיע webhook אבל לא הצלחנו לקרוא אותו.
העתק את מה שרשום ב־`/incoming` ושלח לי. אעדכן קובץ אחד (`lib/leadmanager-mapping.ts`) וזה יעבוד.

## מה עוד לא נמצא כאן

שלב 1 הוא הבסיס בלבד. עוד לא נבנו: חיבור לטקסטר, שליחת תבניות, מנוע החוקים,
הבוט, המשימות והמיילים, הדשבורד והקמפיינים. הם באים בשלבים הבאים —
אחרי שהבסיס עובד אצלך בפועל.
